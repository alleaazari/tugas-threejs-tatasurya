## Cara Menjalankan
1. Buka URL GitHub Pages yang tertera di repository ini.
2. Tunggu beberapa saat hingga seluruh tekstur berhasil dimuat.
3. Geser (*pan*/*zoom*) layar menggunakan *mouse* (OrbitControls aktif).
4. Arahkan *mouse* (hover) ke objek untuk melihat efek *glow* dan perubahan *kursor pointer*.
5. Klik pada salah satu objek (misalnya Matahari, Bumi, atau Roket) untuk melihat detail informasi pada panel di kanan atas.
6. Klik tombol "Masuk VR" di bagian bawah layar untuk mencoba pengalaman WebXR (jika menggunakan device/emulator yang mendukung).
